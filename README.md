Angular Forms Activity
A web application demonstrating the implementation of Template-Driven and Reactive Forms in Angular. This project focuses on form validation, layout structuring using Bootstrap, and deployment via Netlify.

🛠️ Features
Template-Driven Form: Uses ngModel for easy, two-way data binding.

Reactive Form: Uses FormGroup and FormControl for robust, scalable validation logic.

Custom Styling: Integrated a Cream and Red color palette for a polished, "pretty" UI.

Responsive Design: Built with Bootstrap to ensure the forms look great on all devices.

🚀 Getting Started
Clone the repo: git clone https://github.com/owcean/6AWEB.git

Install dependencies: npm install

Run locally: ng serve

Build for production: ng build
